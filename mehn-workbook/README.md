# MEHN Workbook — Checkpoints

**Start here:** open `workbook.html` in your browser. It has the setup checklist, every step with copy-paste code, what you should see, experiments, challenges and troubleshooting.

Each folder in `checkpoints/` is a **complete, working copy** of the project at the end of that step.
Fell behind? Jump to the latest checkpoint and keep going.

## First time only
```
npm install
```

## Run a checkpoint
```
npm run step4
```
Then open http://localhost:3000. Press `Ctrl + C` in the terminal to stop the server.

| Step | Folder | What you learn |
|---|---|---|
| 1 | `step-01-hello-node` | Running JavaScript with Node |
| 2 | `step-02-hello-express` | Your first web server |
| 3 | `step-03-routes` | Different addresses → different pages |
| 4 | `step-04-handlebars` | Views: HTML with blanks (`{{name}}`) |
| 5 | `step-05-each` | Showing a list (`{{#each}}`) |
| 6 | `step-06-mvc` | Splitting code into Model / View / Controller |
| 7 | `step-07-form` | A form to post new messages |
| 8 | `step-08-mongodb` | Saving to MongoDB (only the Model changes!) |

Step 8 needs MongoDB running on your computer (`mongodb://127.0.0.1:27017`).
